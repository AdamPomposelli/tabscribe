# Export examples

Real files exported by Tabscribe from one recording: *Hoa Danh Danh*, a Vietnamese guitar song
(capo 2, 83 BPM, key of F#, transcribed with the default Vote engine). Nothing was edited by hand.

| File | Open it with | Download |
|---|---|---|
| **Guitar Pro 5** (`.gp5`): score, tab, chord boxes | Guitar Pro, MuseScore, TuxGuitar | [Hoa Danh Danh Guitar.gp5](https://github.com/AdamPomposelli/tabscribe/raw/main/export-examples/Hoa%20Danh%20Danh%20Guitar.gp5) |
| **MIDI** (`.mid`) | any DAW or notation app | [Hoa Danh Danh Guitar.mid](https://github.com/AdamPomposelli/tabscribe/raw/main/export-examples/Hoa%20Danh%20Danh%20Guitar.mid) |
| **PDF**: printable score and tab | any PDF reader | [Hoa Danh Danh Guitar.pdf](https://github.com/AdamPomposelli/tabscribe/raw/main/export-examples/Hoa%20Danh%20Danh%20Guitar.pdf) |
